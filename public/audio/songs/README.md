# Local instrumentals

Supply legally obtained instrumental files here. No copyrighted audio is included.

Expected basenames (use `.mp3`, `.ogg`, `.wav`, or `.m4a`):

- `golden-instrumental`
- `how-its-done-instrumental`
- `soda-pop-instrumental`
- `your-idol-instrumental`
- `what-it-sounds-like-instrumental`

Reload Vite after adding files; rebuild for production. Missing tracks play an original synthesized playground beat, not a recreation of these songs. The parent menu lists availability. Only one track plays at a time; local tracks loop until changed or stopped.
